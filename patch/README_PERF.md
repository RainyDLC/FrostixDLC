# Ambience: оптимизация FPS

Скопируй `src/` поверх проекта с заменой (4 файла + дождь). Ambience.java и миксины не трогались.

1. Кастомный туман (включён по умолчанию, главный пожиратель FPS)
   - убраны 2 полноэкранные копии за кадр (цвет RGBA8 + глубина DEPTH32);
   - туман смешивается блендингом, а не перерисовкой всего экрана;
   - пиксели без тумана: discard. Формула и картинка те же.
2. Мокрый мир (SSR)
   - убрана копия глубины за кадр;
   - трассировка на 48 шагов запускается только там, где отражение реально видно (> 1/255).
3. Кастомный дождь
   - sin/cos колец из таблицы (было ~20к тригонометрий за кадр);
   - капли/рябь/брызги за спиной камеры не отправляются на GPU.

Прямое чтение глубины имеет авто-откат: если драйвер не даст, рендерер сам вернётся на копию глубины, эффект не пропадёт.
