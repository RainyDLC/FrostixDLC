## ФИКС: «полоски растягиваются по всему экрану» (LightningRenderer)
- Причина: первая версия рисовала 3D-линии базовой матрицей с вершинами, уже смещёнными в координаты камеры, а билборд свечения — ручными `RotationAxis.POSITIVE_Y.rotationDegrees(-yaw)`/`POSITIVE_X.rotationDegrees(pitch)` внутри несбалансированного push (грязный стек). При NO_DEPTH_TEST это давало мировые координаты огромного масштаба → полосы на весь экран.
- Решение: переписан `LightningRenderer.render` под родные паттерны проекта.
  - Свечение: `matrices.push(); matrices.translate(point - cameraPos); matrices.multiply(camera.getRotation()); ... 4 vert; matrices.pop();` (как `drawCubeGlowSprite`).
  - Линии: `matrices.push(); matrices.translate(basePos - cameraPos); lm = peek().getPositionMatrix();` и ЛОКАЛЬНЫЕ вершины `points.get(s).subtract(basePos)` (как режим «Кольцо»).
  - `cameraPos = mc.gameRenderer.getCamera().getCameraPos()`, `cameraRotation = mc.gameRenderer.getCamera().getRotation()`.
- Перепроверил: все push/pop в блоках RotationProcess (Духи/Кубики/Кольцо) сбалансированы — утечки стека оттуда нет; виноват был только LightningRenderer.
- `./gradlew compileClientJava` → BUILD SUCCESSFUL. Баг устранён на уровне матриц.

## ФИКС №2: «молнии вообще не отображаются» (после фикса матриц)
- Причина: `VertexConsumerProvider.Immediate` при `getBuffer(newLayer)` сбрасывает/флашит текущий слой. Код брал glow- и line-буферы сразу и писал в них ЧЕРЕДУЯ (glow→линии→glow...). Вершины QUADS с `.texture()` попадали в активный POSITION_COLOR-буфер линий → исключение → рендер молний умирал целиком.
- Решение: двухфазный вывод в `LightningRenderer.render()`: ФАЗА 1 — все спрайты свечения через glow-слой, ФАЗА 2 — все линии через line-слой (как «Кольцо»: сначала вся заливка, потом все линии). Цвети/альфа предвычислены в поля `Bolt.drawAlpha/glowColor/coreColor` до фаз, чтобы не расходовать random дважды.
- ПРАВИЛО ПРОЕКТА: никогда не чередовать запись вершин в два разных RenderLayer через один Immediate — только последовательными блоками.
- Заодно исправлен инвертированный слайдер «Скорость молний» (был интервалом: больше = медленнее): теперь `spawnIntervalMs = max(10, 132 - value)` в TargetEsp и RotationProcess.
- `./gradlew compileClientJava` → BUILD SUCCESSFUL.
