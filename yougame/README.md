# TargetESP Scan — Delta base

Публичная версия содержит только режим сканирующей линии. Других режимов TargetESP и PNG-ресурсов здесь нет.

## Установка

1. Перенести содержимое `src/main` в `src/main` проекта с сохранением путей.
2. Добавить элементы из `MIXINS_TO_ADD.json` в массив `client` файла `delta.mixins.json`, не создавая второй массив.
3. Убедиться, что существующий client initializer вызывает `DeltaWorldRenderTypes.initialize()`.
4. Зарегистрировать `TargetESP` в реестре модулей базы так же, как остальные модули.

Если пакет накладывается поверх полной приватной версии Delta, старые Java-рендереры остальных режимов
нужно исключить из публичного дерева исходников: scan-only модуль их не использует.

Настройки: насыщенность, скорость, основной цвет, включение двухцветного переливания, второй цвет и яркость/glow.

Шейдер использует скин и текстуру брони только как альфа-маску поверхности. Отдельная PNG эффекта не требуется.
