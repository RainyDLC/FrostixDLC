# Quick HUD для FrostixDLC

Порт архива `quick-hud-evaware-port.zip` в исходники RainyDLC из FrostixDLC.
Базовый commit порта: `322173983e4def0ff1218cfa5d8ddfcb487ed0c3`.
Перед публикацией сохранены обновления main до `1944012d1ec07a4ac060a7dc0f63f75389f9661a`.
Проект использует Minecraft **26.2 / Java 25**, а не 1.21.4 из исходного архива.

## Установка архива изменений

1. Сохраните копию своих исходников и локальных изменений.
2. Распакуйте архив **в корень FrostixDLC** с заменой файлов. Рядом должны находиться
   `RainyDLC`, `docs`, `tests` и `build-client.ps1`. Это изменения, не полный репозиторий.
3. На Windows с установленными JDK 25, CMake и инструментами Visual Studio запустите:

```powershell
.\build-client.ps1
```

Итоговый загрузчик создаётся штатным workflow: `LegitBuilder.jar` и
`build/release/LegitBuilder.jar`. Отдельный Gradle JAR НЕ заменяет этот загрузчик.

## Управление

- Модуль Interface включён по умолчанию при новой инициализации. Существующий конфиг
  модулей всё ещё может переопределить включение.
- В открытом чате: ЛКМ — перемещение, колесо — масштаб, ПКМ — меню элемента.
- Меню: размер 50–200%, прозрачность 10–100%, свечение 0–200%, сброс внешнего вида.
- Координаты, масштаб, прозрачность и свечение сохраняются в `config/hatek/hud.json`.
- При закрытии чата меню закрывается, захват мыши сбрасывается, изменения сохраняются.
- В чате пустые списки показывают демонстрационные строки; в обычной игре — только
  реальные данные. TargetHUD в чате показывает собственного игрока.

## Что перенесено

15 элементов Quick HUD: Watermark, ArrayList, HotKeys, Potions, StaffList,
CoolDowns, Notifications, Ticks, Ping, FPS, BPS, XYZ, TotemCounter, TargetInfo,
Armor. Существующий кастомный хотбар и Media 2D/3D сохранены.

Использованы оригинальные MSDF-атласы bold, medium, quick, icons_nurik и util.png.
Геометрия Quick: заголовок 16, строка 11, отступ 6, скругление 4.5 GUI-пикселя.
Учитываются левое смещение planeBounds и визуальное центрирование текста/иконок/».
Недостающие в bold символы берутся из оригинального medium, включая «» в уведомлениях.

Панели используют снимок игрового мира через существующий LiquidBackdrop, собственный
25-сэмпловый Gaussian-проход в GUI-пайплайне и тёмную подложку. Размытие локальное,
не заменяет фон всей игры. Свечение и оттенки следуют текущему цвету темы клиента.
Анимации строк и размеров клиппируются, активные модули сортируются по ширине.
ArrayList автоматически выравнивается вправо при переносе в правую половину экрана.
TargetHUD плавно появляется/исчезает, сглаживает здоровье и след урона.
Броня и предметы рук автоматически переходят к вертикальному виду у краёв экрана.

StaffList определяется по названиям команд/префиксам scoreboard (admin/moder/helper/
staff/owner/админ/модер/хелпер/куратор). Статус Vanish означает отсутствие игрока
из подходящей scoreboard-команды в tab list — это эвристика, не гарантия серверного vanish.
CoolDowns получает точные оставшиеся тики из ItemCooldowns; если предмет убран из
инвентаря, отображается идентификатор его cooldown group вместо перевода названия.
TPS оценивается по интервалам пакетов времени, не является серверной телеметрией.

## Упаковка ресурсов

Оригинальные ресурсы без потерь сохранены в Java-частях `dev.hatek.quickembedded`.
В репозитории бинарные PNG отдельно не дублируются. Для восстановления исходных
PNG/JSON в `RainyDLC/src/embedded/quick/` выполните:

```powershell
python scripts/restore_quick_assets.py
```

Скрипт проверяет SHA-256 каждого файла и не перезаписывает изменённые ресурсы.
В присланном ZIP исходные PNG/JSON также доступны напрямую.
Проверенные SHA-256 находятся в `manifest.tsv`; Java-классы с байтами уже включены
в `dev.hatek.quickembedded`, поэтому для обычной сборки Python не нужен.
Загрузка текстур осуществляется через DynamicTexture с линейным sampler, независимо
от доступности resource pack при позднем подключении.

После изменения атласов/метрик обновите SHA-256 в manifest и пересоздайте классы:

```powershell
python examples/embedded-resources/embed_bytes.py --manifest RainyDLC/src/embedded/quick/manifest.tsv --out RainyDLC/src/client/java --package dev.hatek.quickembedded
```

Полные GLSL-источники дополнительно встроены в QuickShaderSources и выдаются
CompilationCache через существующий ChamsShaderCacheMixin, в том числе при reload.
При изменении GLSL поддерживайте синхронность `.fsh` и QuickShaderSources.

## Проверки и ограничения

```powershell
cd RainyDLC
.\gradlew.bat compileClientJava quickHudRegression
```

- Компиляция клиента и 41 headless-проверка проходят на JDK 25.
- Проверены метрики и центрирование шрифтов, SHA-256 встроенных PNG, ограничения
  масштаба, premultiplied-alpha для предметов, совместимость GUI-пайплайнов,
  bounded queue уведомлений. GLSL MSDF/blur связан с vanilla vertex shader
  `position_tex_color` с помощью glslangValidator.
- Исходная ошибка HOTKEYS/showHOTKEYS устранена; сохранён канонический KEYBINDS.
- Прозрачность текстов, иконок, скинов и эффектов применяется при extraction.
  Для обычных предметов применена к итоговому premultiplied-alpha item-atlas blit.
  Редкие oversized/PIP-модели используют другой ванильный путь и требуют игровой
  проверки: отдельная обработка их прозрачности не добавлялась.
- Проверка в запущенном Minecraft, фактическое применение миксинов и поздний инжект
  на Windows здесь не выполнялись. Успех компиляции/GLSL не означает подтверждённый
  внешний вид и работу в игре.
- Финальный LegitBuilder workflow в Linux-среде не выполнен: отсутствуют PowerShell,
  CMake и Windows/Visual Studio toolchain. Финальный LegitBuilder.jar не прилагается.
