# Frostix HUD

HUD модуля `Interface` использует отдельный компактный стиль: полупрозрачный графитовый фон, тонкий контур, холодный голубой акцент и размеры шрифтов 9.5–11 GUI-пикселей. Оформление вдохновлено предоставленным Quick HUD, но реализация использует существующие `Render2D`/`HFont`; исходники, шейдеры и ресурсы референса не скопированы. ClickGUI не изменён.

## Виджеты

- `Watermark`: Frostix, ник игрока, FPS и локальные часы компьютера.
- `Keybinds`: карточка Hotkeys с назначенными клавишами; активные модули выделены.
- `HUD Stats`: пинг, количество тотемов в инвентаре (включая вторую руку), горизонтальная скорость в BPS. При недоступном пинге отображается `— ms`, а не ложный ноль. BPS — модуль горизонтальной скорости игрока, умноженный на 20, не измерение TPS сервера.
- `Active Modules`: включённые модули, кроме самого Interface, отсортированные по ширине названия. Если места по высоте не хватает, последняя строка показывает `+N modules`; если нет места даже для строки, список скрывается.
- `Target HUD`: компактная цель с аватаром, полосой здоровья, поглощением и расстоянием. Приоритет — цель AttackAura, затем живая сущность под прицелом; без цели карточка скрыта.
- `HUD Notifications`: последние три изменения состояния модулей, срок отображения три секунды. Вход в мир не генерирует ложных уведомлений. Уведомления не сохраняются.
- `Effects`, `Armor HUD`, `Custom Hotbar` и медиа сохраняют существующие функции.

Новые переключатели включены по умолчанию. Элементы можно перемещать ЛКМ и масштабировать колёсиком при открытом чате/экране. Позиции и масштабы сохраняются в `config/hatek/hud.json`; ключи прежних элементов не переименованы. Ручная позиция ватермарки сохраняется при запуске; изменение Watermark Position возвращает её на выбранный якорь.

## Проверки

Проверка геометрии, независимая от Minecraft (из корня репозитория):

```sh
javac -d build/hud-tests RainyDLC/src/client/java/dev/hatek/client/module/impl/render/interf/HudGeometry.java tests/HudGeometryRegression.java
java -cp build/hud-tests dev.hatek.client.module.impl.render.interf.HudGeometryRegression
```

Проверены семь случаев: обычный экран, двойной масштаб, ровно одна строка, нехватка места, позиция ниже экрана, нулевая высота строки и NaN-позиция.

В Linux выполнены `compileClientJava` и промежуточная Fabric-сборка `build -x test` с JDK 25. Это **не** итоговая LegitBuilder-сборка. Обязательный финальный путь на Windows с PowerShell и MSVC: `./build-client.ps1`, затем `java -jar ./LegitBuilder.jar --inspect` (см. `BUILD.md`). В Linux этот путь заблокирован отсутствием PowerShell и Windows-инструментов.

Визуально проверен локальный макет геометрии, не игровой захват. Следующие проверки требуют запуска в Minecraft:

1. Включить Interface; проверить FPS, ник, часы, пинг и тотемы в слотах и второй руке.
2. Назначить клавиши двум модулям, переключить их; проверить подсветку и уведомления (исчезают через три секунды).
3. Навести прицел на игрока/моба, затем проверить цель AttackAura, нулевое здоровье и поглощение.
4. Проверить длинные названия, эффекты с уровнями/длительностью и множество активных модулей.
5. Переместить и масштабировать каждый элемент; закрыть экран, перезапустить клиент и проверить сохранение, особенно ватермарки. Сверить попадание мышью с фактическими границами.
6. Проверить разные GUI Scale/разрешения, Watermark Position, босс-бары, отсутствие цели/эффектов/кейбиндов, отключение отдельных виджетов и повторный вход в мир.
7. Проверить кастомный хотбар, броню, медиа и неизменность ClickGUI после загрузки через LegitBuilder.
